# Fragewürfel

Ein Würfelspiel mit Freunden, jeder auf seinem eigenen Gerät. Verbindet euch mit einem 4-stelligen Spiel-Code.

- ⭐ 1× Stern: Du stellst eine Frage an alle
- 🐱 2× Katze: Du darfst nochmal würfeln
- ⬜ 3× leer: Der Nächste ist dran
- 🃏 2 Joker pro Person: Eine Frage auslassen

## Spielen

- **Im Browser oder am Handy:** https://cillx111.github.io/W-rfel/
- **Windows-Programm:** [Fragewuerfel-Windows.zip herunterladen](https://github.com/CillX111/W-rfel/releases/download/windows/Fragewuerfel-Windows.zip)
  1. Rechtsklick auf die ZIP-Datei → **Alle extrahieren**
  2. **Fragewuerfel.exe** doppelklicken
  3. Falls Windows warnt: **Weitere Informationen** → **Trotzdem ausführen**

Das Windows-Programm wird automatisch neu gebaut, wenn `index.html` geändert wird.
